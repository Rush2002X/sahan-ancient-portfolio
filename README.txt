SAHAN RASHMITHA — ANCIENT SRI LANKAN PORTFOLIO

HOW TO RUN
1. Extract this folder.
2. Open index.html in a browser, or open the folder in VS Code and use Live Server.
3. Keep the images folder next to index.html so all image links work.

CUSTOMIZE
- Replace images/backgrounds/*.jpg with your preferred background photos, keeping the same filenames.
- Update your email in index.html (search for your.email@example.com).
- Update the social links to your actual profile URLs.
- Replace sample project descriptions and add links to your real projects.
- All image paths are relative, so the site can be moved or hosted as a folder.

FOLDER STRUCTURE
index.php
images/assets/          Separate ornamental, skill, social, and button assets
images/backgrounds/     Hero, about, project and contact background photos
images/sri-lankan-tusker/  Interactive 3D tusker model and textures
